# 双人体重小本本

两个人的体重记录 App（PWA）。极简设计：只做「记录 + 多维度对比」。

线上地址（GitHub Pages）：`https://wowayuan11-elio.github.io/weight-tracker-app/`

## 功能

| 页面 | 功能 |
|------|------|
| 记录 | 两人输入即存；可切换日期补记；大数字显示最新体重与变化 |
| 趋势 | 7/30/90/全部 · 每人独立曲线 · 滑动查看任意一天 · 目标虚线 |
| 统计 | 本周 vs 上周 · 本月 vs 上月 · 累计变化与减重速率 · 全量记录（可编辑/删除） |

## 数据安全

1. **本机存储**：数据存 localStorage，写入即持久
2. **GitHub 自动云备份**（可选）：数据变更后 3 秒自动推送到私有仓库 `weight-tracker-data`，只有账号主人可见
3. **一键手动备份**：系统分享面板直达备忘录；支持备份文本 / 存档链接两种格式
4. **换机迁移**：新设备登录 GitHub 配置云备份 → 点「从云端恢复」即可

## 技术栈

纯 HTML/CSS/JS，零依赖、零框架、零构建。Service Worker 离线缓存。
